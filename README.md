# Arco V7 / V8 设计交接包

两版均为历史设计评审原型，不是正式官网或最新 Brief 的完整实现。保留页面原有文案与交互，不将本次打包视为设计认可。

## 在线与本地使用

- 入口：`index.html`；版本入口：`index-v7.html`、`index-v8.html`。
- 解压后可直接打开 HTML；也可在解压目录运行 `python3 -m http.server 8080`，访问 http://localhost:8080/。
- 编辑文案与结构：各版本 HTML。
- 编辑样式：`v7/page.css`、`v7/generated.css` 或 `v8/page.css`、`v8/generated.css`。
- 编辑交互：`v7/page.js` 或 `v8/page.js`。
- 素材和字体：各版本下的 `assets/`、`media/`、`fonts/`；请保留相对目录关系。
- 无构建步骤，无 npm 依赖。源码可用 VS Code / Cursor 等编辑器修改。

## 边界

- 下载按钮、对话、AI 任务和 D5 衔接等以原型现有实现为准；不代表真实后端服务、正式下载或经核验的生成因果。
- 本包仅含运行所需页面、CSS、JavaScript、媒体与字体，不含原始项目 JSON、内部任务书、聊天记录、测试日志和凭证。
- 素材用于此次授权设计评审与修改，不随交接包扩大第三方素材授权范围；正式发布前需核对素材、字体授权、产品承诺及正式链接。
- 线上预览不等于在线协同编辑；同事下载源码后修改，修改完成后需重新部署。
